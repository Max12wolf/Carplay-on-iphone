# Auto-Dashboard

Eine Web-App (PWA) fürs iPhone im Auto: Uhr, Tacho per GPS, Musiksteuerung, Telefon-Favoriten, Navi- und WhatsApp-Start.

## Veröffentlichen mit GitHub Pages
1. Alle Dateien dieses Ordners in ein Repository legen.
2. Unter Settings > Pages den Branch `main` und den Ordner `/ (root)` wählen.
3. Die Adresse in Safari öffnen, dann Teilen > Zum Home-Bildschirm.

## Kurzbefehle (einmalig in der Kurzbefehle-App anlegen)
Musik Zurück, Musik Start, Musik Weiter, Kontakte anrufen und Blitzer. Der Blitzer-Link lässt sich in den App-Einstellungen ändern.

## Hinweis
Bei Änderungen an Dateien die Versionsnummer `V` in `sw.js` hochzählen, damit Geräte die neue Version laden.
Favoriten werden nur lokal auf dem Gerät gespeichert.
